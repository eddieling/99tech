# 99tech

A React application built with Vite and configured for deployment on Vercel.

## Tech Stack

- **Vite** - Fast build tool and development server
- **React** - JavaScript library for building user interfaces
- **Vercel** - Deployment platform

## Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

### Build

Build for production:

```bash
npm run build
```

### Lint

Run ESLint:

```bash
npm run lint
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## Deployment

This project is configured for deployment on Vercel. The `vercel.json` file contains the necessary configuration for automatic deployment.

Simply connect your repository to Vercel, and it will automatically deploy on every push to the main branch.
